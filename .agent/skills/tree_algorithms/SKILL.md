# 二叉树算法动画 SKILL

## 概述

本 SKILL 提供二叉树在各种常见操作下（中序遍历递归/非递归、先序建立、复制、计算深度、统计结点、中序线索化）的 Manim 动画模板。所有模板基于二叉链表数据结构，采用经典的圆形结点和左右连线布局，确保风格一致、简洁大气，适合教育类解说视频。

## 支持的二叉树操作

| 编号 | 操作名称 | 文件名 | 描述 | 时间复杂度 |
|------|---------|------|-----------|-----------|
| 1 | 中序遍历的递归算法 | `inorder_recursive.py` | 递归展示左子树、根结点、右子树的访问顺序 | O(n) |
| 2 | 中序遍历的非递归算法 | `inorder_non_recursive.py` | 借助栈(Stack)可视化模拟中序遍历的过程 | O(n) |
| 3 | 先序建树过程 | `preorder_build_tree.py` | 动态演示按先序序列逐个生成结点建立二叉链表 | O(n) |
| 4 | 复制二叉树 | `copy_tree.py` | 递归复制当前树至右侧（或新树层），展示结构克隆 | O(n) |
| 5 | 计算二叉树的深度 | `calculate_depth.py` | 自底向上收集左、右子树深度并取最大值加一 | O(n) |
| 6 | 统计二叉树结点个数 | `count_nodes.py` | 递归展示左右子树结点统计过程以及结果累加 | O(n) |
| 7 | 二叉树中序线索化 | `inorder_threading.py` | 针对特定子树建立前驱、后继线索(虚线箭头)的过程 | O(n) |

## 公共组件

- `tree_base.py`：二叉树可视化基类，提供统一的结点生成、基于极坐标或经典分层递归布局的二叉树排版、边缘连线以及指针游标高亮。

## 动画设计规范

### 数据结构规定
- **二叉链表**：根结点由 `root` 引用，含有 `left` 和 `right` 指针，未分枝则为 None。
- **线索二叉树**：空闲的左右指针可转换为前驱/后继虚线/细线箭头。
- **辅助结构**：部分算法涉及栈（Stack）的进出，可使用矩形框组展示。

### 颜色规范
- **默认结点**：主色调蓝色 `BLUE`，边框 `WHITE`，风格简洁明快
- **遍历访问结点**：高亮黄色 `YELLOW`
- **新建/复制/线索化高亮**：绿色 `GREEN` 或红色 `RED`
- **空结点/返回信号**：灰色 `GRAY`
- **文字与连线**：白色 `WHITE`，线索采用虚线并标识箭头方向

### 动画节奏
- 结点状态切换与着色：0.5 秒
- 游标移动/出入栈控制：0.5 - 0.8 秒
- 等待解说：每次关键步骤停顿 0.5 - 1.0 秒

### 代码讲解规范
- **代码块呈现**：在涉及到有关具体代码讲解时，必须在场景中呈现对应的代码块（例如使用 `Code` 类展示），以便读者直观理解代码逻辑与动画视觉变化的对应关系。

## 使用方式

在 ManimAgent 生成二叉树相关动画时：
1. 继承 `tree_base.py` 中的 `TreeBase`。
2. 调用 `self.setup_tree(data)` 或动态调用 `self.create_node(val)` 生成所需二叉树。
3. 利用高亮功能 `self.highlight_node(node)` 和箭头连线展示算法动态。
