# 排序算法动画 SKILL

## 概述

本 SKILL 提供 9 种经典排序算法的 Manim 动画模板，每个模板均可直接用于生成教学动画视频。

## 支持的排序算法

| 编号 | 算法名称 | 文件 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|---------|------|-----------|-----------|--------|
| 1 | 直接插入排序 | `insertion_sort.py` | O(n²) | O(1) | 稳定 |
| 2 | 折半插入排序 | `binary_insertion_sort.py` | O(n²) | O(1) | 稳定 |
| 3 | 希尔排序 | `shell_sort.py` | O(n^1.3) | O(1) | 不稳定 |
| 4 | 冒泡排序 | `bubble_sort.py` | O(n²) | O(1) | 稳定 |
| 5 | 快速排序 | `quick_sort.py` | O(nlogn) | O(logn) | 不稳定 |
| 6 | 简单选择排序 | `selection_sort.py` | O(n²) | O(1) | 不稳定 |
| 7 | 堆排序 | `heap_sort.py` | O(nlogn) | O(1) | 不稳定 |
| 8 | 归并排序 | `merge_sort.py` | O(nlogn) | O(n) | 稳定 |
| 9 | 基数排序 | `radix_sort.py` | O(d·n) | O(n) | 稳定 |

## 公共组件

- `sorting_base.py`：数组可视化基类，提供统一的数组显示、元素高亮、交换动画等公共方法

## 动画设计规范

### 颜色规范
- **默认元素**：蓝色 `BLUE`
- **正在比较**：黄色 `YELLOW`
- **正在交换**：红色 `RED`
- **已排序/已就位**：绿色 `GREEN`
- **枢轴/基准**：紫色 `PURPLE`
- **分组/子序列**：橙色 `ORANGE`

### 动画节奏
- 比较操作：0.3-0.5 秒
- 交换操作：0.5-0.8 秒
- 步骤间暂停：0.3 秒
- 阶段间暂停：1.0 秒

### 布局规范
- 标题居顶部
- 数组居中显示
- 元素方块大小：0.8×0.8
- 元素间距：0.1
- 索引标签在元素下方

### 代码讲解规范
- **代码块呈现**：在涉及到有关具体代码讲解时，必须在场景中呈现对应的代码块（例如使用 `Code` 类展示），以便读者直观理解代码逻辑与动画视觉变化的对应关系。

## Context7 集成

本 SKILL 已集成 Context7 MCP 服务器，在生成 Manim 动画代码前会自动拉取最新的 Manim 官方文档，
确保使用的 API 与当前 Manim 版本兼容，避免生成过时或不存在的接口调用。

使用时在 Prompt 中添加 `use context7` 即可自动查询 Manim 文档，或直接指定库 ID：
```
生成冒泡排序的 Manim 动画 use context7
```

## 使用方式

在 ManimAgent 生成排序动画时 **（必须执行以下步骤）**：

1. **获取最新文档**（强制）：
   - 调用 Context7 (`use context7` 或相关工具) 查询 Manim 最新文档。
   - 重点关注: `Scene`, `Square`, `Text`, `VGroup` 及动画相关 API。
   - 示例 Prompt: `查询 Manim 的 Scene 类及基本图形 API 文档 use context7`

2. **识别排序算法类型**

3. **加载对应模板文件**

4. **根据知识文档调整参数**（数组数据、步骤说明等）

5. **验证 API 兼容性**：
   - 使用 Context7 返回的文档检查模板代码中的 API 是否过时。
   - 如有不兼容，根据最新文档修正代码。

6. **生成最终动画代码**
