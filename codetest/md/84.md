## 算法步骤

#### 二叉排序树的插入的算法步骤
① 若二叉排序树为空，则将待插入结点*S 作为根结点插入空树。
② 若二叉排序树非空，则将key 与根结点的关键字T−>data.key 进行比较：
(a)若key 小于T−>data.key，则将*S 插入左子树；
(b)若key 大于T−>data.key，则将*S 插入右子树。

## 算法分析

#### 二叉排序树的插入的算法分析
&emsp;&emsp; 二叉排序树插入操作需要先沿树查找合适的插入位置，因此时间复杂度与查找操作相同。若二叉排序树较为平衡，插入一个结点的时间复杂度为 O(log n)；若二叉排序树退化为单支树，则插入一个结点的时间复杂度为 O(n)。若采用递归方式插入，空间复杂度主要来自递归调用栈，为 O(h)。平均情况下为 O(log n)，最坏情况下为 O(n)。

## Python 代码

```python
ENDFLAG = -1


class ElemType:
    def __init__(self, key, otherinfo=""):
        self.key = key  # 关键字域
        self.otherinfo = otherinfo  # 其他域


class BSTree:
    def __init__(self, e=None):
        self.data = e
        self.lchild = None  # 左孩子指针
        self.rchild = None  # 右孩子指针

    def insert_bst(self, e):
        # 当二叉排序树中不存在关键字等于e.key的数据元素时，则插入该元素
        if self.data is None:  # 如果当前树为空，即找插入位置
            self.data = e  # 当前树结点的数据域置为e
            self.lchild = BSTree()  # 左子树置为空
            self.rchild = BSTree()  # 右子树置为空
        elif e.key < self.data.key:  # e的关键字小于当前节点数据域的关键字
            self.lchild.insert_bst(e)  # 插入左子树
        elif e.key > self.data.key:  # e的关键字大于当前节点数据域的关键字
            self.rchild.insert_bst(e)  # 插入右子树

    def create_bst(self, input_values):
        # 依次读入一个关键字为key的结点，将此结点插入二叉排序树中
        for key in input_values:
            e = ElemType(key)
            self.insert_bst(e)

    def in_order_traverse(self):
        # 中序遍历二叉树的递归算法
        if self.data is not None:  # 若二叉树非空
            self.lchild.in_order_traverse()  # 中序遍历左子树
            print(self.data.key, end=' ')  # 访问根结点
            self.rchild.in_order_traverse()  # 中序遍历右子树


if __name__ == '__main__':
    n = int(input())
    input_str = input()
    input_values = [int(x) for x in input_str.split()]
    tree = BSTree()
    tree.create_bst(input_values)  # 创建二叉树
    key = int(input())
    e = ElemType(key)
    tree.insert_bst(e)
    tree.in_order_traverse()    # 进行中序遍历输出结果
```
