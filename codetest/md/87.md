## 算法步骤

#### B-树的查找的算法步骤
&emsp;&emsp;将给定值key与根结点的各个关键字K1, K2, …, Kj（1 ≤ j ≤ m − 1）进行比较，由于该关键字序列是有序的，因此查找时可采用顺序查找，也可采用折半查找。如果在自上而下的查找过程中，找到了值为key 的关键字，则查找成功；如果直到叶子结点也未找到值为key 的关键字，则查找失败。
查找时：
① 若key = Ki（1 ≤ i ≤ j），则查找成功；
② 若key < K1，则顺着指针P0 所指向的子树继续向下查找；
③ 若Ki < key < Ki+1（1 ≤ i ≤ j − 1），则顺着指针Pi 所指向的子树继续向下查找；
④ 若key > Kj，则顺着指针Pj 所指向的子树继续向下查找。

## 算法分析

#### B-树的查找的算法分析
&emsp;&emsp; M是B-树的阶，N 是树中所有关键字的数目，在最坏的情况下，查找操作可能需要从根节点开始，一直查找到叶节点，每次比较都移动到下一个子树。最坏情况下的时间复杂度：$O(\log_{M} N)$，虽然实际操作中可能会更早找到目标关键字，但平均情况下，查找操作的时间复杂度仍然是$O(\log_{M} N)$，空间复杂度为O(1)。

```python
"""B-树查找（由算法 ID 87 的 C++ 逻辑改写，索引改用 Python 的 0 起始）。"""

from bisect import bisect_left
from dataclasses import dataclass, field


@dataclass
class BTreeNode:
    keys: list[int] = field(default_factory=list)
    children: list["BTreeNode"] = field(default_factory=list)


@dataclass
class SearchResult:
    node: BTreeNode | None
    index: int
    found: bool


def search_btree(root: BTreeNode | None, key: int) -> SearchResult:
    """返回所在结点和索引；未找到时返回应插入的叶结点及位置。"""
    node = root
    parent = None
    index = 0
    while node is not None:
        index = bisect_left(node.keys, key)
        if index < len(node.keys) and node.keys[index] == key:
            return SearchResult(node, index, True)
        parent = node
        if not node.children:
            break
        node = node.children[index]
    return SearchResult(parent, index, False)
```
