## 算法步骤

#### 二叉排序树的递归查找的算法步骤
① 若二叉排序树为空，则查找失败，返回空指针。
② 若二叉排序树非空，将给定值key 与根结点的关键字T−>data.key 进行比较：
(a)若key 等于T−>data.key，则查找成功，返回根结点地址；
(b)若key 小于T−>data.key，则递归查找左子树；
(c)若key 大于T−>data.key，则递归查找右子树。

## 算法分析

#### 二叉排序树的递归查找的算法分析
&emsp;&emsp; 含有n 个结点的二叉排序树的平均查找长度和树的形态有关。当先后插入的关键字有序时，构成的二叉排序树蜕变为单支树。树的深度为n，平均查找长度为(n+1)/2（和顺序查找相同），这是最差的情况。显然，最好的情况是，二叉排序树的形态和折半查找的判定树的形态相似，其平均查找长度和$\log_{2} n$成正比。若考虑把n 个结点按各种可能的次序插入二叉排序树中，则有n！棵二叉排序树（其中有的形态相同）。可以证明，综合所有可能的情况，就平均而言，二叉排序树的平均查找长度仍然和$\log_{2} n$是同数量级的。因此，二叉排序树的递归查找的时间复杂度为$O(\log_{2} n)$，空间复杂度为$O(\log_{2} n)$。

## Python 代码

```python
class ElemType:
    def __init__(self, key, otherinfo=""):
        self.key = key  # 关键字域
        self.otherinfo = otherinfo  # 其他域


class BSTree:
    def __init__(self, e=None):
        self.data = e
        self.lchild = None  # 左孩子指针
        self.rchild = None  # 右孩子指针

    def insert_bst(self, e):
        # 当二叉排序树中不存在关键字等于e.key的数据元素时，则插入该元素
        if self.data is None:  # 如果当前树为空，即找插入位置
            self.data = e  # 当前树结点的数据域置为e
            self.lchild = BSTree()  # 左子树置为空
            self.rchild = BSTree()  # 右子树置为空
        elif e.key < self.data.key:  # e的关键字小于当前节点数据域的关键字
            self.lchild.insert_bst(e)  # 插入左子树
        elif e.key > self.data.key:  # e的关键字大于当前节点数据域的关键字
            self.rchild.insert_bst(e)  # 插入右子树

    def create_bst(self, input_values):
        # 依次读入一个关键字为key的结点，将此结点插入二叉排序树中
        for key in input_values:
            e = ElemType(key)
            self.insert_bst(e)

    def search_bst(self, key):
        # 在当前二叉排序树中递归地查找某关键字等于key的数据元素
        # 若查找成功，则将该元素返回，否则返回None
        if self.data is None or self.data.key == key:
            return self.data.key if self.data else None  # 查找结束
        elif key < self.data.key:
            return self.lchild.search_bst(key)  # 在左子树中继续查找
        else:
            return self.rchild.search_bst(key)  # 在右子树中继续查找


if __name__ == '__main__':
    n = int(input())
    input_str = input()
    input_values = [int(x) for x in input_str.split()]
    tree = BSTree()
    tree.create_bst(input_values)  # 创建二叉树
    key = int(input())
    p = tree.search_bst(key)  # 查找该关键字在二叉树中的位置，若没有返回None
    if p is None:
        print("#")
    else:
        print(p)
```
