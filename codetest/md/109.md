# 算法 id=109 制作素材

## 算法步骤

#### B-树的插入的算法步骤
① 在B−树中查找给定关键字的记录，若查找成功，则插入操作失败，否则将新记录作为空指针ap 插入查找失败的叶子结点的上一层结点（由q 指向）。
② 若插入新记录和空指针后，q 指向的结点的关键字个数未超过m − 1，则插入操作成功，否则转入步骤3。
③ 以该结点的第⌈m/2⌉个关键字K⌈m/2⌉为拆分点，将该结点分成3个部分：
K⌈m/2⌉左边部分、K⌈m/2⌉、K⌈m/2⌉右边部分。K⌈m/2⌉左边部分仍然保留在原结点中；K⌈m/2⌉右边部分存放在一个新创建的结点（由ap 指向）中；关键字为K⌈m/2⌉ 的记录和指针ap插入q的双亲结点。因q的双亲结点增加一个新的记录，所以必须对q 的双亲结点重复步骤2和步骤3的操作，依次类推，直至由q指向的结点是根结点，转入步骤4。
④ 由于根结点无双亲，则由其分裂产生的两个结点的指针ap 和q，以及关键字为K⌈m/2⌉的记录构成一个新的根结点。此时，B−树的高度增加1。

## 算法分析

#### B-树的插入的算法分析
&emsp;&emsp; M是B-树的阶，N 是树中所有关键字的数目，在最坏的情况下，查找操作可能需要从根节点开始，一直查找到叶节点，每次比较都移动到下一个子树，最后进行插入，最坏情况下的时间复杂度：$O(\log_{M} N)$，虽然实际操作中可能会更早插入目标关键字，但平均情况下，插入操作的时间复杂度仍然是$O(\log_{M} N)$，空间复杂度为O(1)。

```python
"""3 阶 B-树插入（由算法 ID 109 的 C++ 逻辑改写）。"""

from bisect import bisect_left
from dataclasses import dataclass, field


ORDER = 3  # 最多 3 个子树、2 个关键字；第 3 个关键字触发分裂


@dataclass
class BTreeNode:
    keys: list[int] = field(default_factory=list)
    children: list["BTreeNode"] = field(default_factory=list)


def insert_btree(root: BTreeNode | None, key: int) -> tuple[BTreeNode, bool]:
    """插入关键字，返回 (新根结点, 是否插入成功)；重复值不插入。"""
    if root is None:
        return BTreeNode([key]), True

    def insert_into(node: BTreeNode):
        index = bisect_left(node.keys, key)
        if index < len(node.keys) and node.keys[index] == key:
            return False, None

        if node.children:
            inserted, promoted = insert_into(node.children[index])
            if not inserted:
                return False, None
            if promoted is not None:
                middle, right = promoted
                node.keys.insert(index, middle)
                node.children.insert(index + 1, right)
        else:
            node.keys.insert(index, key)

        if len(node.keys) < ORDER:
            return True, None

        # 结点溢出：中间关键字上移，左右两部分各保留一个结点。
        split_at = len(node.keys) // 2
        middle = node.keys[split_at]
        right = BTreeNode(node.keys[split_at + 1:],
                          node.children[split_at + 1:] if node.children else [])
        node.keys = node.keys[:split_at]
        if node.children:
            node.children = node.children[:split_at + 1]
        return True, (middle, right)

    inserted, promoted = insert_into(root)
    if promoted is not None:
        middle, right = promoted
        root = BTreeNode([middle], [root, right])
    return root, inserted
```
