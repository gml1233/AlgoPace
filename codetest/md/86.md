## 算法步骤

#### 二叉排序树的删除的算法步骤
&emsp;&emsp;首先从二叉排序树的根结点开始查找关键字为key 的待删结点，如果树中不存在此结点，则不做任何操作；否则，假设被删结点为*p（指向结点的指针为p），其双亲结点为*f（指向结点的指针为f），PL 和PR 分别表示其左子树和右子树。
不失一般性，可设*p 是*f 的左孩子（右孩子情况类似）。下面分3 种情况进行讨论。
①若*p 结点为叶子结点，即PL 和PR 均为空树。由于删去叶子结点不破坏整棵树的结构，因此只需修改其双亲结点的指针即可：f−>lchild = NULL;
②若*p 结点只有左子树PL 或者只有右子树PR，此时只要令PL 或PR 直接成为其双亲结点*f 的左子树即可：f−>lchild = p−>lchild;（或f−>lchild = p−>rchild;）
③若*p 结点的左子树和右子树均不空。在删去*p 结点之前，中序遍历该二叉树得到的序列为{…CLC…QLQSLSPPRF…}，在删去*p 之后，为保持其他元素之间的相对位置不变，可以有两种处理方法：
(a) 令*p 的左子树为*f 的左子树，而*p 的右子树为*s 的右子树，f−>lchild = p−>lchild; s−>rchild = p−>rchild;
(b) 令*p 的直接前驱（或直接后继）替代*p，然后再从二叉排序树中删去它的直接前驱（或直接后继）。当以直接前驱*s 替代*p 时，由于*s 只有左子树SL，因此在删去*s 之后，只要令SL 为*s 的双亲*q 的右子树即可。p−>data = s−>data; q−>rchild = s−>lchild;

## 算法分析

#### 二叉排序树的删除的算法分析
&emsp;&emsp; 二叉排序树的删除操作需要先查找到待删除结点，然后根据该结点的孩子情况进行处理。若待删除结点有两个孩子，还需要在其左子树或右子树中寻找前驱或后继结点。整个过程的时间复杂度与树的高度 h 有关，因此时间复杂度为 O(h)。若二叉排序树较为平衡，h 约为 log n，此时删除操作的平均时间复杂度为 O(log n)；若二叉排序树退化为单支树，h = n，此时最坏时间复杂度为 O(n)。若采用递归方式实现删除，空间复杂度主要来自递归调用栈，因此空间复杂度为 O(h)。平均情况下为 O(log n)，最坏情况下为 O(n)。

## Python 代码

```python
class ElemType:
    def __init__(self, key, otherinfo=""):
        self.key = key  # 关键字域
        self.otherinfo = otherinfo  # 其他域


class BSTree:
    def __init__(self, e=None):
        self.data = e
        self.lchild = None  # 左孩子指针
        self.rchild = None  # 右孩子指针

    def insert_bst(self, e):
        # 当二叉排序树中不存在关键字等于e.key的数据元素时，则插入该元素
        if self.data is None:  # 如果当前树为空，即找插入位置
            self.data = e  # 当前树结点的数据域置为e
            self.lchild = None  # 左子树置为空
            self.rchild = None  # 右子树置为空
        elif e.key < self.data.key:  # e的关键字小于当前节点数据域的关键字
            if self.lchild is None:
                self.lchild = BSTree(e)
            else:
                self.lchild.insert_bst(e)  # 插入左子树
        elif e.key > self.data.key:  # e的关键字大于当前节点数据域的关键字
            if self.rchild is None:
                self.rchild = BSTree(e)
            else:
                self.rchild.insert_bst(e)  # 插入右子树

    def create_bst(self, input_values):
        # 依次读入一个关键字为key的结点，将此结点插入二叉排序树中
        for key in input_values:
            e = ElemType(key)
            self.insert_bst(e)

    def delete_bst(self, key):
        # 删除二叉树中的指定结点值的结点
        p = self
        f = None
        # 下面的while循环从根开始查找关键字等于key的结点 * p
        while p is not None:
            if p.data.key == key:
                break
            f = p
            if p.data.key > key:
                p = p.lchild
            else:
                p = p.rchild
        if p is None or p.data is None:  # 找不到被删结点则返回
            return
        # 处理三种情况：左右子树均不为空、无右子树、无左子树
        if p.lchild is not None and p.rchild is not None:
            # 左右子树均不为空，找到左子树中的最大结点（前驱）
            q = p
            s = p.lchild
            # 在左子树继续查找前驱结点
            while s.rchild is not None:
                q = s
                s = s.rchild
            # 用前驱结点值替换当前结点值
            p.data = s.data
            # 重接右子树
            if q != p:
                # 重接右子树
                q.rchild = s.lchild
            else:
                # 重接左子树
                q.lchild = s.lchild
        else:
            # 无右子树的情况
            if p.rchild is None:
                # 重接其左子树
                child = p.lchild
            # 无左子树的情况
            elif p.lchild is None:
                # 重接其右子树
                child = p.rchild
            # 被删除结点为根结点
            if f is None:
                self.data = child.data if child else None
                self.lchild = child.lchild if child else None
                self.rchild = child.rchild if child else None
            elif f.lchild == p:
                # 挂接到f的左子树
                f.lchild = child
            else:
                # 挂接到f的右子树
                f.rchild = child

    def in_order_traverse(self):
        # 中序遍历二叉树的递归算法
        if self.data is not None:  # 若二叉树非空
            if self.lchild:
                self.lchild.in_order_traverse()  # 中序遍历左子树
            print(self.data.key, end=' ')  # 访问根结点
            if self.rchild:
                self.rchild.in_order_traverse()  # 中序遍历右子树


if __name__ == "__main__":
    n = int(input())
    input_str = input()
    input_values = [int(x) for x in input_str.split()]
    tree = BSTree()
    tree.create_bst(input_values)  # 创建二叉树
    key = int(input())
    tree.delete_bst(key)
    tree.in_order_traverse()    # 进行中序遍历输出结果
```
